חיבור ל־Home Assistant

הכתובת והמפתח נשמרים רק בטלפון הזה. הם נשלחים רק ל־Home Assistant שלך, ולא לשרת של Hania. אחרי החיבור נשמר בדפדפן גם סימון קטן, בלי הכתובת והמפתח, כדי שהדף הראשי של Hania360 יוכל להראות את מצב הבית.

מה צריך להגדיר ב־Home Assistant (פעם אחת)
  1. כתובת https: בתוסף Tailscale לבחור Share Home Assistant with Serve, או Nabu Casa, או דומיין משלך.
  2. לאשר את האפליקציה: הגדרות ← מערכת ← רשת ← HTTP server ← ב־CORS allowed origins להוסיף https://smart.hania360.com, לשמור ולהפעיל מחדש. עם Tailscale serve צריך שם גם להפעיל Trust X-Forwarded-For ולהוסיף ל־Trusted proxies את 127.0.0.1.
    בגרסאות לפני 2026.8 זה נמצא בקובץ configuration.yaml, תחת http: (cors_allowed_origins).
  3. התוסף Jewish Calendar (הגדרות ← מכשירים ושירותים ← הוספה), עם העיר ודקות הדלקת הנרות שלך.
  4. מפתח גישה: לוחצים על שם המשתמש למטה משמאל ← אבטחה ← Long-lived access tokens ← יצירה. מעתיקים לכאן.

ההגדרות שלך ב־Home Assistant

המתגים והמספרים שכבר יש לך לשבת, לדוד ולתריסים (מחבילה או מ"עוזרים"). שינוי כאן משנה מיד ב־Home Assistant.

    מה מופיע כאן

    המכשירים

    מה כל מכשיר בבית. אפשר לשנות בכל זמן.

    מה הבית עושה לבד

    מפעילים מה שרוצים, ובסוף לוחצים "שמירה ב־Home Assistant". כל שעה בשבת ובחג לפי השעון של השבת, וההחלטות ההלכתיות לפי מה שאתם נוהגים.

    שעון שבת למכשירים נוספים

    פלטה, אורות, מזגן: מתי נדלקים לפני שבת, מתי נכבים ונדלקים שוב בשבת, ומה קורה בצאתה.

    מה בדיוק ייכתב ב־Home Assistant

    האוטומציות של Hania מתחילות ב־"Hania ·". אפשר גם להדביק ידנית, כל אחת בנפרד: אוטומציה חדשה ← ⋮ ← עריכה ב־YAML.
